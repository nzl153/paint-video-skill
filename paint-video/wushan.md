# 设色打斗画风（雾山五行风）

毛笔勾线加平涂和一块暗面，青绿远山配暖色落日，只有火和朱红是亮色；打斗靠连贯的身体动作、冲击帧和火墨炸屏。来自短片《试拳》：19.5 秒，无声。主角拿棍，对手是光膀子的大个子，从崖顶对峙打到一记砸地。引擎和整部短片的代码都在仓库的 `inkfight-kit/`。

这套的第一版是黑白水墨：人物是单笔剪影，姿势按 12fps 跳帧。看起来不连贯、不像人体，而且雾山本身就是有颜色的，所以整套推倒重做成现在的设色版。别走回那条路。

## 什么时候用这套

- 用户要打斗、武侠、动作戏，或者点名雾山五行、国风动画、设色水墨。
- 纯 2D canvas，不用 p5.brush。每帧绘制 20–100ms，19.5 秒 468 帧用 4 个进程渲染不到 1 分钟。
- 没有声音。要声音的话，参考 `piying-kit/sound/synth.py`，自己合成太鼓、破风、撞击、风声。

## 起新项目

1. 复制 `inkfight-kit/` 到新目录，`npm install`（会下载 puppeteer-core，装之前先问用户）。已经装好的话，连 `node_modules` 一起复制，就不用重装。
2. `studio.html` 的脚本顺序：`config` → `mo.js`（引擎）→ `body.js`（人体）→ `moves.js`（招式库）→ `scenes/land.js`（布景）→ `scenes/fight.js`（整场戏）→ `scenes/moves-lab.js`（招式工作台）。新片就换掉 `fight.js`。
3. `render.mjs` 和蜡笔那套一样（`--sheet`、`--strip`、`--frames --workers=4`、`--encode`、`--loop`、`--crop`）。没有全局相机，`--crop-at` 会报错。
4. **直接用现成的 `mo.js` 和 `body.js`，别重写人体和动作插值**。IK、踩点、棍不入地、`track` 的连贯都是一轮轮调出来的，推倒重写就全丢了。想改造型，改身材表、配色和衣服零件；想换兵器，照着 `staff` 加一种。09-30 有个模型冷启动时把人体重写成硬折多边形、自己写了分段缓动，结果人像纸片，动作一顿一顿，还慢。
5. **`probe.mjs` 是调打斗最有用的工具**：不开浏览器，直接算关节在世界里的坐标。
   ```
   node probe.mjs "[7.96,7.98,8.0].map(t=>[t, jointOf(HERO,heroAt(t),'tip'), jointOf(BRUTE,bruteAt(t),'head')])"
   ```
   棍梢到底有没有打中下巴、勾拳从头顶上方多少像素擦过，拿数字对，别拿截图猜。

## 引擎（`src/mo.js`）

- **调色板** `PAL`：
  - 纸 `#efe6d2`，墨 `#1c1714`；
  - 天是青往暖过渡：`skyTop #c3cfc6` → `skyLow #f0d7ad`；
  - 三层青绿山：`mt1`、`mt2`、`mt3`；
  - 赭色崖：`rock`、`rockTop`；
  - 点睛色：朱红 `red`、落日 `sun`、火 `fire`、`fireLt`。

  一整片青绿里只让火、头带和落叶是暖亮色。
- **`track(t, K)`**：Catmull-Rom 曲线，动作一路穿过关键帧，不在每一帧上停一下。这是「连贯」的关键：原来用分段缓动，每到一个关键帧都会顿一下。
  - 关键帧写 `[t, 姿势, 'hold']` 就在那里停稳，首尾两帧也会停稳；
  - 值可以是嵌套对象，由 `lin()` 按权重叠加；
  - 每个关键帧的字段必须齐全，所以姿势统一用 `hp({...})`、`bp({...})` 和默认值合并。
- **`stepTrack(t, K)`** 只管脚，写法是 `[t, 世界x, 离地?, 缓动?, 'slide'?]`：
  - 两帧 x 不同就是迈一步，中间自动抬脚；
  - 写了 `slide` 是贴地滑（被震退、刹车）；
  - 脚和身体分开写，站着的脚才不会跟着胯滑。
- **体块** `capsule(中线, 半宽函数)`：沿中线撑开的封闭形，两头是圆的，肢体、躯干、飘带都用它。
- **平涂加暗面** `part(poly, 底色, 暗色, {d, line})`：先涂暗色，再把底色往光的方向挪 `d` 盖上去，没盖住的那道月牙就是暗面。几乎不花时间，立体感立刻就有了。
- **勾线** `outline()`：背光一侧粗、迎光一侧细，粗细带一点抖，偶尔断一笔。雾山的线就靠这个粗细对比。
- **干笔** `brush()`：一束几十根细毫，按噪声断开出飞白，用在山脊、崖边、草、裂纹上。
- **特效零件**：
  - `impact('inv'|'red')`：去色、拉满对比、反相，或者再压一层朱红；
  - `burstLines`、`speedLines`：放射速度线、平行速度线；
  - `splat`：墨点；
  - `finish()`：纸纹 multiply，再加暗角。
- **光**：全局 `LIGHT = [.62, -.78]`，从右上来。人物画的时候按朝向翻转。落日在右边，大个子是逆光，主角是顺光。

## 人体（`src/body.js`）

- **身材**：身高约 175 个局部单位。
  - 大腿 44、小腿 42、躯干 54、上臂 28、前臂 25，头半径 10.5；
  - 每段有自己的半宽表，用 `pw([[s, 半宽], ...])` 写：大腿根粗、膝细，小腿肚鼓；
  - 大个子另有一套数，肩背和拳头都大一圈。
- **姿势字段**：
  - `hh` 胯高：贴地时会被腿长卡住，不会把腿拉长；
  - `lean` 前倾，`tw` 扭身（前肩往前送），`head` 点头，`brow` 眯眼；
  - `hF`、`hB` 是手相对肩的位置；
  - `staff: {a, gF, gB, free}`：棍的角度，前手、后手在棍上的握处（从棍中心量），`free` 表示后手松开；
  - `air` 腾空时胯不再被腿卡住，`tuck` 把脚收到 `rF`、`rB`（相对胯）。
- **棍跟着前手走**：棍穿过前手的实际位置，后手用 IK 去够握处，棍永远握在手里。
- **棍不入地**：棍头戳到地面以下时，棍顺着手滑上去。拖棍上挑时，棍梢正好贴着地擦过去。
- **画的顺序**：后手 → 后腿 → 身后飘的东西（发尾、头带、后片袍裾、兽皮）→ 身子 → 前腿 → 前片袍裾 → 头 → 棍 → 前手。后面的手脚用 `far()` 压暗一档，前后靠这个分开。
- **衣服**：
  - 袍裾是一片梯形（`skirt()`），不能用一根管子：管子会被看成第三条腿；
  - 前片跟着前大腿，后片被风往后吹；
  - 袖子往肘口张开，前臂换深色护腕，不然整条胳膊像塑料管；
  - 胯要单独垫一块，否则大腿根会鼓出一个包。
- **侧脸** `headPoly()`：蛋形上加三个鼓包，下巴、鼻尖、后脑勺；头发和胡子用 `capOf()` 在头上围一片。眼睛是一道上眼睑加瞳仁，外眼角在后，眉毛和眼睛要分开，不然会连成一个「十」字。
- **飘动** `ribbon()`：从根部一节节往后吹，风来自 `wind` 加身体速度 `vel`，冲刺时衣摆自然被拉平。

## 招式库（`src/moves.js`）

**编打斗先用招式库，别从零手写关键帧**。24 个招式和挨打反应都已经调好：蓄力、出手、顿帧、余势的帧数，脚怎么迈，都在里面。`plan()` 负责按时间把它们拼成 `track` / `stepTrack` 直接能吃的表。

```js
const A = plan(HERO, { x: 820, dir: 1, u: 2.2, guard: { brow: 1 } });   // 拿棍的（kind 自动是 staff）
const B = plan(BRUTE, { x: 1510, dir: -1, u: 2.3 });                    // 空手的（fist）
B.wait(.5).do('dash', { dist: 150 }).do('punch', { at: 2.0 });          // at：这一招的接触时刻落在 2.0 秒
A.do('blockMid', { at: 2.0 }).do('thrust', { at: 3.1, dx: -12 });
B.do('hitBody', { at: 3.1 });                                           // 挨打的反应也用 at 对准同一时刻
const a = A.build(), b = B.build();
body(BRUTE, b.at(t)); body(HERO, a.at(t));                              // 每帧取姿势
a.hits;                                                                 // [{t, name, joint, line, miss}]，放冲击帧、震屏用
a.point(a.hits[0]);                                                     // 那一刻打人部位的世界坐标
```

- **`do(name, {at, dx, miss, pose})`**：
  - `at` 让这一招的接触帧正好落在某个时刻，攻守双方用同一个 `at` 就对上了；
  - `dx` 让这一招额外往前（负数往后）多走一段，局部单位，接触前走完，站着的那只脚会贴地垫过去；
  - `miss: true` 标记这一招打空（对方闪开了），不出火花、不震屏；
  - `pose` 给这一招的每一帧追加字段，比如 `{ brow: 1 }`。
- **上一招没收完就接下一招**：`at` 早于上一招结束时，会从那一刻的姿势直接接上，等于取消后摇。连招就靠这个。
- `wait(秒)` 原地停，`until(时刻)` 停到某个时刻，`pose(dt, 姿势)` 手写一帧。
- 时间倒退、招式名写错会直接报错，不会悄悄画错。

**招式表**。「够得着」是这一招开始时，胯到接触点的水平距离，单位是局部单位，乘 `u` 就是像素；「高」是接触点离地多高。按这两个数加上对方身体的宽度（约 15–20）来摆站位：

| 招式 | 谁用 | 路 | 够得着 | 高 | 说明 |
|---|---|---|---|---|---|
| `thrust` 直刺 | 棍 | 中 | 206 | 116 | 收棍、上步一刺，打肚子、胸口 |
| `chop` 劈 | 棍 | 高 | 198 | 123 | 棍举过头往后，上步劈下 |
| `rising` 撩 | 棍 | 高 | 141 | 188 | 矮身拖棍，梢子擦地，从下往上挑下巴 |

| `blockHigh` 架 | 棍 | 高 | | | 棍横举过头，接劈砸；会被压得一沉、后滑 |
| `blockMid` 格 | 棍 | 中 | | | 棍竖在身前拨开刺、拳；后滑半步 |
| `punch` 直拳 | 拳 | 中 | 111 | 126 | 拧身蓄力，上步打到底 |

**棍长拳短，距离就是戏**：棍的够得着是拳的两倍左右。拿棍的要拉开距离才打得到，空手的必须挤进来才打得到。所以两人的距离天然会来回变：挤进来、被打出去、再挤进来。别把两人钉在一个距离上互砍。

**检查工作台**（`src/scenes/moves-lab.js`，不进成片）：
- `node render.mjs --loop=moves --strip=<a>:<b>`：每个招式 1.6 秒轮流演一遍，对面站一个靶子，接触那一帧打一个红点。`LOOPS.moves.index` 列出每个招式从第几秒开始。
- `--loop=duel`：一段 9.8 秒的示范对打，全部用 `plan()` 拼成：7 次接触、4 次打中，高中低三路，有腿有肩，距离远、近、远、近、远来回变，最后一撩把人打飞。编新打斗前先看它的写法。
- 对准接触点用 `probe.mjs`：打出 `a.point(h)` 和对方的 `head`、`chest`、`hndF` 坐标，差 30 像素以内就算打上了。示范对打调了四轮才对齐：第一轮大个子的双拳砸在了主角身后，最后一撩的棍梢穿过人头 220 像素。

**扩展新招式**：照着 `MOVES` 里现成的抄。每个招式写 `keys`（相对时间、和架势不同的字段、`dx`）、`ff` / `fb`（脚的相对位移）、`hit`（接触时刻）、`joint`（打人的部位）。写完加进 `moves-lab.js` 的 `LIST`，渲一遍看过再用。

## 编一场打斗：五段模板

先照这个模板把接触表填出来，再动手。每一段都要写清三件事：**距离怎么变、用哪几招（不能和前面重复）、谁占上风**。

| 段 | 大约占比 | 要做到 |
|---|---|---|
| 试探 | 10–15% | 对峙不超过 3 秒；一方先出手，被挡住或者打空。观众在这里看清两人各拿什么、谁长谁短 |
| 交锋 | 25–30% | 两三个来回，各有得失，至少一次真打中；出现第一次明显的距离变化（逼退或挤进） |
| 失势 | 20% | 主角被压制：被打中、被撞开、被逼到边上。至少用一招不是兵器的（腿、肩、摔） |
| 反转 | 20% | 一个停顿（亮相），然后主角用一招前面没用过的，打破对方的节奏 |
| 终结 | 10–15% | 全片最重的一下：冲击帧、最大的震屏、被打的一方飞出去或倒地；之后留 1–2 秒落地 |

填完用「打击感和节奏」一节的指标对一遍：接触密度、最长空档、招式重复次数、两人距离曲线。

## 打斗怎么编

- **先定接触点，再倒推站位**：先用 `probe.mjs` 算出击中那一刻武器梢和目标（下巴、架起的手臂）在哪，再回头调两人的 x。试拳里调过的三处：
  - 上挑：两人贴得太近，棍会从对方肚子里穿过去。棍要沿着对方身前划上去，在 −0.3 rad 左右命中下巴，所以站位要拉开到武器半径那么远；
  - 勾拳：主角不是原地蹲，而是「矮身往里钻」，拳从头顶上方约 40 像素处擦过；
  - 砸落：先砸在对方架起的胳膊上（冲击帧），再连人压到地面（炸开）。一口气砸到地上，人会直接撞进对方身体里。
- **蓄力、出手、余势三段都要有**：蓄力关键帧用 `hold` 停稳，出手 0.1–0.15 秒，余势留 0.3–0.5 秒的定格亮相。
- **冲刺是真的在跑**：每步约 0.33 秒，落脚点在胯前约 20 单位。后脚要比身体先迈，不然身体走远了、脚还钉在原地，人会被腿长拽着趴下去。
- **冲击帧**：命中那一刻给 2 帧反相、1–2 帧朱红，再回到正常画面并配猛抖（`shake`）；其他帧一律不反相。
- **残影**：快动作时往回取 2–3 个时刻，用单色低透明度画（`actors({ghost})`）。挥击再加一道白芯墨边的月牙 `smear()`。
- **火尾**：取棍梢最近 0.2 秒的轨迹，**宽度跟着梢子的速度走**。按时间等宽画，梢子慢的时候会缩成一根橙色香肠。
- **炸屏和墨退**：`bloom()` 是一团火舌边缘圆润的火或墨，外圈火、内芯亮黄、中间墨，一路胀满全屏；下一镜反过来用同一个形状，从中间化开，一圈火边退出画面。火舌噪声频率别太高，太高就成了漫画爆炸。

## 打击感和节奏（硬指标，写完分镜和做完都要对一遍）

打斗片最常见的失败是「慢吞吞、没打击感」：两个人端着兵器站着，隔好几秒才碰一下，每个动作都是同一个不紧不慢的速度。下面的数按 24fps、1080p 中景算：

- **接触密度**：
  - 打斗段里每 1–1.5 秒至少发生一次接触（打中、格挡、兵器相撞）或一次明确的攻防换位；
  - 两人都没有攻防动作超过 2 秒，就是冷场；
  - 15–30 秒的片子，至少 6 次接触，其中至少 2 次真打中身体，最后一下是全片最重的；
  - 开场对峙加收势合计不超过全片的 40%，对峙本身不超过 3 秒；
  - 「点到为止」「刀停在脖子边」这种不打中的收尾会显得温吞，前面没打够就别用。
  - **密度是下限，不是目标**。09-30 第二次冷启动排了 15 次接触，指标全部达标，但两人从头到尾钉在原地，同一只胳膊你砍我挡重复了 15 遍，看起来就是「砍来砍去」。次数够了而花样不够，比次数少还难看。
- **招式要变**：
  - 同一个动作（同样的出手方向、高度、手法）全片最多用两次；
  - 高、中、低三路都要出现；
  - 至少有一次不是兵器的攻击或防守，比如踢、肘、肩撞、摔、抓腕、借力；
  - 每次交手的结果也要变：格挡、闪空、打中、被震退、兵器脱手、反被抓住。
- **空间要变**：
  - 每一段打斗至少有一次明显的位置变化：推进、逼退、换边、上高处或跳下、一方倒地、跃起；
  - 两个人的距离要一直在变，贴身、一臂、一兵器长、拉开冲刺，这几档要来回切；
  - 用 `probe.mjs` 打印两人 x 随时间的曲线，一条近乎水平的线就是站桩。
- **全身发力，不能只动胳膊**：
  - 出手前后脚要动，至少是一个垫步、上步或转脚；
  - 胯和肩要一起转（`tw`、`lean`），重心往出手方向压；
  - 被打中的一方从脚到头都要变形，只在身上溅一点红不算反应；
  - 检查方法：把一次出手前后的帧并排放，只有手臂在变就不合格。
- **兵器比例**：
  - 单手刀或剑的刃长大约是前臂加手的长度，不能比整条胳膊长；
  - 棍、枪、长柄刀要双手握；
  - 挥砍时肘是弯的，胳膊从头到尾笔直地端着兵器，看起来就像在拿棍子戳人。
- **快慢对比**：
  - 出手（蓄力最后一帧到命中）3–4 帧，也就是 0.12–0.17 秒；
  - 蓄力 4–8 帧，往出手的反方向拉，要看得出但要短；
  - 余势 6–10 帧；只有全片最重的一两下才定格亮相 0.4 秒以上；
  - 走位一步 0.25–0.35 秒，不要慢于 0.4 秒；
  - 慢只留给意义（对峙的眼神、收势），动作一律快。整场所有动作一个速度，就是慢吞吞。
- **关键帧写法**：
  - 两个关键帧相隔超过 0.6 秒、中间人又在动，多半就是太慢，要么拆成几下，要么压短；
  - 出手那一段首尾用 `hold`，中间别再插缓动关键帧；
  - 用 `probe.mjs` 量武器梢每帧走多远：中景里出手那几帧每帧至少 60–120 像素，低于 30 像素看起来就是在比划。
- **顿帧**：命中那一刻双方姿势冻住 2–3 帧，冲击帧就叠在这几帧上，然后立刻放开。
- **被打的一方必须有反应**：
  - 头甩、身子折、脚往后滑 40–120 单位（`stepTrack` 的 `slide`）、倒地；
  - 格挡的一方也要被推得晃一下、脚滑半步；
  - 挨了一下没反应，观众就会觉得没打中。
- **震屏**：只在命中和砸地时给，格挡约 6 像素，打中约 12，最重的一下约 20，指数衰减 0.2–0.3 秒。震屏是在给这一下打分：每次都震，就等于没震。
- **连招的节奏别等距**：一次交手是 2–4 下的一串，比如「哒、哒、停、砰」，最后一下最重、停得最久。
- **自检**：
  - 列出全片每次接触的时刻，算最长的无接触间隔；
  - 用 `--strip` 看每次命中前后各 4 帧：前面要看得到蓄力，命中要有顿帧和冲击帧，后面要看得到被打的一方在退；
  - 找一个没看过的人或者只看一遍的眼光：看完能不能说出「谁打中了谁几下」。

## 转场：打斗片用动作剪辑，不加装饰

这一节覆盖 SKILL.md「每个接缝都要转场」那一条。

- **打斗段镜头之间直接切在动作中间**（cut on action）：前一镜挥出，后一镜落下；或者前一镜蓄力，后一镜已经在出手。动作本身就是转场，连贯感从这里来。
- **禁止和剧情无关的装饰转场**：满屏扫一道色带、翻页、叠化、每个接缝都擦一笔。09-30 那支冷启动片在每个接缝都横扫一道浅色大笔刷，看起来就像莫名其妙翻了一页。
- **切镜必须真的换一个视角**，否则就是跳切，观众看到的不是「换了镜头」，而是「卡了一下」。
  - 前后两镜至少满足一条：景别差一档以上（全景、中景、近景、特写），机位角度明显不同（侧面、过肩、仰拍、俯拍），或者主体换了人；
  - 同一个侧面机位只是放大缩小 10%–25%、稍微歪一点，就是跳切。09-30 第二次冷启动每 3 秒这样切一次，看起来像每 3 秒卡一帧；
  - 找不到值得换的视角，就别切，一个持续跟拍的镜头比乱切连贯得多；
  - 不跳轴：两人在画面里的左右关系，切镜前后保持不变。
- 可以用的只有画面里本来就有的东西：打斗溅起的墨、火、尘，飞过镜头的叶子、兵器、人的身体挡住画面。
- 开头可以淡入、墨化开，结尾可以墨退、淡到纸，这两处不算装饰。
- 15–30 秒的片子 4–7 镜就够了，打斗高潮尽量放在一个持续跟拍的镜头里。

## 镜头

试拳一共 6 镜：
1. 远景对峙：主角转棍上架，对手跺脚；
2. 眯眼特写：一片大红叶横扫过去，接下一镜；
3. 跟拍对冲；
4. 交手：一个中景持续跟着两人，勾拳、上挑、打飞、再冲都在这一个镜头里；
5. 仰拍跃起砸下，相机跟着人往上走；
6. 墨退，拉远，淡到纸。

**打斗段尽量少切**，用一个持续跟拍的中景，连贯感主要来自这里。

## 踩过的坑

- **雾要画在世界坐标里**：山脚的雾如果按屏幕坐标画，相机一上下摇就出现断层。
- **炸屏之后别再画草**：画的顺序是先草、再爆炸、最后落叶和纸纹，不然草会浮在满屏的墨上面。
- **跨帧没有状态**：尘土、火星的随机值一律用 `hash`，种子取固定的量。用每帧都变的位置当种子，会一闪一闪。
- **远景人物别太小**：在画面里占画高 1/4 以上，远景 `CAM.s` 取 1.3 左右。
- **还没做好的地方**（下次想提高可以从这里下手）：
  - 特写里的脸偏简单；
  - 躺在地上的人像一团；
  - 上挑命中前约有一帧，棍和对方胸口叠在一起；
  - 打斗段只有 6.3–12.9 秒这 6.6 秒，前面的对峙、特写、冲刺和后面的墨退合起来占了三分之二，按上面的指标算偏长。

## 原作观察（来自一次冷启动的资料研究，做造型时参考）

- 人物是硬边平涂，暗面是顺着形体的硬边色块；背景是湿染和破色，比人物松得多。人物周围减纹理，用雾和明度把人和背景分开。
- 外轮廓有提按，头发、眉骨、下颌、衣襟是短促的粗楔形；内部线更细。飞白只在快速拖笔、岩壁和特效里出现，静态的脸轮廓是清楚的。
- 山头干而重，山腹是纵向的皴擦，不是一圈圈平行的等高线；雾绕着山把轮廓截断，前景最实。
- 色彩不全是低饱和：元素对撞时接近纯橙黄配饱和青蓝，由墨黑托住。
- 导演访谈提到动作是一拍二和 24fps 一拍一混着用：出手一拍一，其余可以一拍二。
