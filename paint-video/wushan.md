# 设色打斗画风（雾山五行风）

毛笔勾线加平涂和一块暗面，青绿远山配暖色落日，只有火和朱红是亮色；打斗靠连贯的身体动作、冲击帧和火墨炸屏。来自短片《试拳》：19.5 秒，无声。主角拿棍，对手是光膀子的大个子，从崖顶对峙打到一记砸地。引擎和整部短片的代码都在仓库的 `inkfight-kit/`。

这套的第一版是黑白水墨：人物是单笔剪影，姿势按 12fps 跳帧。看起来不连贯、不像人体，而且雾山本身就是有颜色的，所以整套推倒重做成现在的设色版。别走回那条路。

## 什么时候用这套

- 用户要打斗、武侠、动作戏，或者点名雾山五行、国风动画、设色水墨。
- 纯 2D canvas，不用 p5.brush。每帧绘制 20–100ms，19.5 秒 468 帧用 4 个进程渲染不到 1 分钟。
- 没有声音。要声音的话，参考 `piying-kit/sound/synth.py`，自己合成太鼓、破风、撞击、风声。

## 起新项目

1. 复制 `inkfight-kit/` 到新目录，`npm install`（会下载 puppeteer-core，装之前先问用户）。已经装好的话，连 `node_modules` 一起复制，就不用重装。
2. `studio.html` 的脚本顺序：`config` → `mo.js`（引擎）→ `body.js`（人体）→ `scenes/land.js`（布景）→ `scenes/fight.js`（整场戏）。新片就换掉 `fight.js`。
3. `render.mjs` 和蜡笔那套一样（`--sheet`、`--strip`、`--frames --workers=4`、`--encode`、`--loop`、`--crop`）。没有全局相机，`--crop-at` 会报错。
4. **`probe.mjs` 是调打斗最有用的工具**：不开浏览器，直接算关节在世界里的坐标。
   ```
   node probe.mjs "[7.96,7.98,8.0].map(t=>[t, jointOf(HERO,heroAt(t),'tip'), jointOf(BRUTE,bruteAt(t),'head')])"
   ```
   棍梢到底有没有打中下巴、勾拳从头顶上方多少像素擦过，拿数字对，别拿截图猜。

## 引擎（`src/mo.js`）

- **调色板** `PAL`：
  - 纸 `#efe6d2`，墨 `#1c1714`；
  - 天是青往暖过渡：`skyTop #c3cfc6` → `skyLow #f0d7ad`；
  - 三层青绿山：`mt1`、`mt2`、`mt3`；
  - 赭色崖：`rock`、`rockTop`；
  - 点睛色：朱红 `red`、落日 `sun`、火 `fire`、`fireLt`。

  一整片青绿里只让火、头带和落叶是暖亮色。
- **`track(t, K)`**：Catmull-Rom 曲线，动作一路穿过关键帧，不在每一帧上停一下。这是「连贯」的关键：原来用分段缓动，每到一个关键帧都会顿一下。
  - 关键帧写 `[t, 姿势, 'hold']` 就在那里停稳，首尾两帧也会停稳；
  - 值可以是嵌套对象，由 `lin()` 按权重叠加；
  - 每个关键帧的字段必须齐全，所以姿势统一用 `hp({...})`、`bp({...})` 和默认值合并。
- **`stepTrack(t, K)`** 只管脚，写法是 `[t, 世界x, 离地?, 缓动?, 'slide'?]`：
  - 两帧 x 不同就是迈一步，中间自动抬脚；
  - 写了 `slide` 是贴地滑（被震退、刹车）；
  - 脚和身体分开写，站着的脚才不会跟着胯滑。
- **体块** `capsule(中线, 半宽函数)`：沿中线撑开的封闭形，两头是圆的，肢体、躯干、飘带都用它。
- **平涂加暗面** `part(poly, 底色, 暗色, {d, line})`：先涂暗色，再把底色往光的方向挪 `d` 盖上去，没盖住的那道月牙就是暗面。几乎不花时间，立体感立刻就有了。
- **勾线** `outline()`：背光一侧粗、迎光一侧细，粗细带一点抖，偶尔断一笔。雾山的线就靠这个粗细对比。
- **干笔** `brush()`：一束几十根细毫，按噪声断开出飞白，用在山脊、崖边、草、裂纹上。
- **特效零件**：
  - `impact('inv'|'red')`：去色、拉满对比、反相，或者再压一层朱红；
  - `burstLines`、`speedLines`：放射速度线、平行速度线；
  - `splat`：墨点；
  - `finish()`：纸纹 multiply，再加暗角。
- **光**：全局 `LIGHT = [.62, -.78]`，从右上来。人物画的时候按朝向翻转。落日在右边，大个子是逆光，主角是顺光。

## 人体（`src/body.js`）

- **身材**：身高约 175 个局部单位。
  - 大腿 44、小腿 42、躯干 54、上臂 28、前臂 25，头半径 10.5；
  - 每段有自己的半宽表，用 `pw([[s, 半宽], ...])` 写：大腿根粗、膝细，小腿肚鼓；
  - 大个子另有一套数，肩背和拳头都大一圈。
- **姿势字段**：
  - `hh` 胯高：贴地时会被腿长卡住，不会把腿拉长；
  - `lean` 前倾，`tw` 扭身（前肩往前送），`head` 点头，`brow` 眯眼；
  - `hF`、`hB` 是手相对肩的位置；
  - `staff: {a, gF, gB, free}`：棍的角度，前手、后手在棍上的握处（从棍中心量），`free` 表示后手松开；
  - `air` 腾空时胯不再被腿卡住，`tuck` 把脚收到 `rF`、`rB`（相对胯）。
- **棍跟着前手走**：棍穿过前手的实际位置，后手用 IK 去够握处，棍永远握在手里。
- **棍不入地**：棍头戳到地面以下时，棍顺着手滑上去。拖棍上挑时，棍梢正好贴着地擦过去。
- **画的顺序**：后手 → 后腿 → 身后飘的东西（发尾、头带、后片袍裾、兽皮）→ 身子 → 前腿 → 前片袍裾 → 头 → 棍 → 前手。后面的手脚用 `far()` 压暗一档，前后靠这个分开。
- **衣服**：
  - 袍裾是一片梯形（`skirt()`），不能用一根管子：管子会被看成第三条腿；
  - 前片跟着前大腿，后片被风往后吹；
  - 袖子往肘口张开，前臂换深色护腕，不然整条胳膊像塑料管；
  - 胯要单独垫一块，否则大腿根会鼓出一个包。
- **侧脸** `headPoly()`：蛋形上加三个鼓包，下巴、鼻尖、后脑勺；头发和胡子用 `capOf()` 在头上围一片。眼睛是一道上眼睑加瞳仁，外眼角在后，眉毛和眼睛要分开，不然会连成一个「十」字。
- **飘动** `ribbon()`：从根部一节节往后吹，风来自 `wind` 加身体速度 `vel`，冲刺时衣摆自然被拉平。

## 打斗怎么编

- **先定接触点，再倒推站位**：先用 `probe.mjs` 算出击中那一刻武器梢和目标（下巴、架起的手臂）在哪，再回头调两人的 x。试拳里调过的三处：
  - 上挑：两人贴得太近，棍会从对方肚子里穿过去。棍要沿着对方身前划上去，在 −0.3 rad 左右命中下巴，所以站位要拉开到武器半径那么远；
  - 勾拳：主角不是原地蹲，而是「矮身往里钻」，拳从头顶上方约 40 像素处擦过；
  - 砸落：先砸在对方架起的胳膊上（冲击帧），再连人压到地面（炸开）。一口气砸到地上，人会直接撞进对方身体里。
- **蓄力、出手、余势三段都要有**：蓄力关键帧用 `hold` 停稳，出手 0.1–0.15 秒，余势留 0.3–0.5 秒的定格亮相。
- **冲刺是真的在跑**：每步约 0.33 秒，落脚点在胯前约 20 单位。后脚要比身体先迈，不然身体走远了、脚还钉在原地，人会被腿长拽着趴下去。
- **冲击帧**：命中那一刻给 2 帧反相、1–2 帧朱红，再回到正常画面并配猛抖（`shake`）；其他帧一律不反相。
- **残影**：快动作时往回取 2–3 个时刻，用单色低透明度画（`actors({ghost})`）。挥击再加一道白芯墨边的月牙 `smear()`。
- **火尾**：取棍梢最近 0.2 秒的轨迹，**宽度跟着梢子的速度走**。按时间等宽画，梢子慢的时候会缩成一根橙色香肠。
- **炸屏和墨退**：`bloom()` 是一团火舌边缘圆润的火或墨，外圈火、内芯亮黄、中间墨，一路胀满全屏；下一镜反过来用同一个形状，从中间化开，一圈火边退出画面。火舌噪声频率别太高，太高就成了漫画爆炸。

## 镜头

试拳一共 6 镜：
1. 远景对峙：主角转棍上架，对手跺脚；
2. 眯眼特写：一片大红叶横扫过去，接下一镜；
3. 跟拍对冲；
4. 交手：一个中景持续跟着两人，勾拳、上挑、打飞、再冲都在这一个镜头里；
5. 仰拍跃起砸下，相机跟着人往上走；
6. 墨退，拉远，淡到纸。

**打斗段尽量少切**，用一个持续跟拍的中景，连贯感主要来自这里。

## 踩过的坑

- **雾要画在世界坐标里**：山脚的雾如果按屏幕坐标画，相机一上下摇就出现断层。
- **炸屏之后别再画草**：画的顺序是先草、再爆炸、最后落叶和纸纹，不然草会浮在满屏的墨上面。
- **跨帧没有状态**：尘土、火星的随机值一律用 `hash`，种子取固定的量。用每帧都变的位置当种子，会一闪一闪。
- **远景人物别太小**：在画面里占画高 1/4 以上，远景 `CAM.s` 取 1.3 左右。
- **还没做好的地方**（下次想提高可以从这里下手）：
  - 特写里的脸偏简单；
  - 躺在地上的人像一团；
  - 上挑命中前约有一帧，棍和对方胸口叠在一起。
