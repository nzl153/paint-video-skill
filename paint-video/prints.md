# 版画系列短片：每段一种版画工艺，SVG 代码生成

用户想要有材质感、不走扁平简约风的系列画面，或者点名版画、孔版、铜版、蓝晒、网点时，读这份。

范例是《远光》：93 秒，一颗蒲公英种子的六段旅程，配乐自己写（见 `music.md`）。全部代码在本仓库的 `prints-kit/`：

```bash
cd prints-kit && npm install
npm run stills    # 六段定格 → out/check/stills.png
npm run sheet     # 抽几拍拼联系表 → out/check/sheet.png
npm run audio     # 渲配乐 → out/yuanguang.wav（采样从 jsDelivr 拉）
npm run video     # 4 路并行出片 → out/yuanguang.mp4（有 wav 就配上）
```

## 先定死一条约束，其余每段都换

六段的地平线都在 y=300，远光都在 (560, 208)，唯一的强调色陶土橙 `#bb5f3c` 只给光用。工艺每段都换，观众靠这两样不动的东西认出这是同一个世界。这和「同一条弧线、每一刀换一种材质」的匹配剪辑是一个思路。

构造线是装饰的一部分，每段都保留：远光的十字准星和虚线同心圆、地平线刻度、`(560, 208)`、`h = 300` 这类坐标小字、轨迹虚线。画面因此像一张带手稿痕迹的原画。

## 六种工艺的做法（`src/plates.js`）

| 段 | 工艺 | 关键做法 |
|---|---|---|
| 盛夏 | 孔版套印 Risograph | 蓝、黄两版各一个 `<g>`，用 `mix-blend-mode:multiply` 叠印。黄版错开 (3,-2) 像套印没对准。天空是网点，越往下越大 |
| 仰望 | 铜版蚀刻 Etching | 断续的横排线，上浓下淡；上部加斜交叉线，用渐变 mask 淡出；山和地面用 clipPath 填斜排线；外面一圈圆角压印框。光源和花头周围用径向 mask 让排线避开，靠留白发光 |
| 风起 | 大理石纹染纸 Marbling | 50 多条平行波线，每个点经过几个旋涡的旋转扭曲，墨、灰蓝、赭三色粗细交替，只裁在地平线以上 |
| 高处 | 蓝晒 Cyanotype | 普鲁士蓝底，边缘不规则，像刷涂的药液。以光为中心做径向渐变，叠一层低频噪声当曝光不匀。白色主体加一点 GaussianBlur，像接触印相；远处的种子用更大的模糊，当成虚焦 |
| 远光 | 凸版网点 Letterpress | 两套旋转网格，墨版 45°、陶土版 15°，模仿真实的网屏角度。网点半径由一个函数决定（离光越近越大）。墨版不随时间变，缓存起来 |
| 尾声 | 植物图版 Botanical plate | 双线框，地面以下是点描的土壤剖面，画出主根和须根。编号的分图（1 绒球、2 单颗种子、3 花、4 花苞），拉丁学名，Pl. VI，比例尺 |

**蒲公英零件**：
- `puff()`：绒球；
- `seed()`：单颗种子，有瘦果、喙和冠毛；
- `leaf()`：狮子牙叶。叶齿锯得太尖显得硬，做成圆弧又像云，定稿是齿尖略朝叶基、尖但不锯。

**动画不闪的关键**：每一帧都用同一个随机种子从头重画。**每个元素消耗的随机数个数必须固定**。比如一颗种子掉了，也要照样把它那几个随机数取掉，否则后面所有元素都会跟着跳。

## 让画面讲事

第一版每段都只是「一棵蒲公英加一种工艺」，种子都是无名的，看完的反馈是「很单调，没什么表现」。病根不在不够热闹，在**没有在讲事**。加了下面三样才立住：

1. **主角和伙伴**：
   - 绒球上指向光的那几颗画得更实；
   - 伙伴们先被风吹散，各拖一条往不同方向分岔的虚线轨迹；
   - 主角等到全曲最高点那阵风才走，走之前回头看一眼（冠毛转向身后、速度慢下来）；
   - 后几段，伙伴变成远处的小点，最后在山脊上各自亮成一盏灯；
   - 不用出现人，也能看懂这是长大、分开、各自亮着。
2. **一天的时间**：在版画上面叠一层正片叠底，色调从傍晚到入夜，最深时是倒数第二段，尾声天亮。光源周围用径向 mask 留出一圈不压。所有光点由各段单独返回成 `glow` 层，画在夜色上面。
3. **铅笔题签**：版画边角写「1/6 盛夏」，数字用斜体衬线，标题用楷体。真的版画就是这么签的，所以不算硬加的字幕。

**动感**：
- 镜头以光为中心一路缓推，高潮推到最近，尾声拉回全景；
- 风的强弱写成拍子的函数，跟配乐的密度曲线走；
- 一道风浪约每 10 拍从左往右扫过草地；
- 萤火虫按周期从草里升起、淡掉；
- 每段至少有一样持续在动的东西：云、流纹、漂浮的种子、网点在呼吸。

## 换场：每次都是下一段工艺自己的「印法」

都写在 `src/anim.html` 的 `M` 里：遮罩 id 固定叫 `tm`，新的一版放在 `<g mask>` 里盖住上一版。

| 进入 | 印法 |
|---|---|
| 仰望 | 揭纸：线性渐变从左下往右上推，揭口带一道淡影 |
| 风起 | 流纹冲开：一条波浪形的边从左往右推，边缘做模糊 |
| 高处 | 显影：以光为中心的径向渐变向外扩开 |
| 远光 | 压网点：一格格圆点从光源往外长大，直到连成整版 |
| 尾声 | 走墨：像滚筒一样从上往下滚过 |

主体在换场时位置要一致，或者插值过去，不然两版会叠出重影。根部不能动，挪了像在走路。

## 管线

- `tools/tempo.mjs`：按乐谱的速度表算出拍和秒的换算。画面里一切按拍写，配乐改了速度，画面会跟着走。
- `src/plates.js`：每段一个 `F(t)`，返回 `{ defs, body, glow }`，各段的 id 都带段号，不会冲突。
- `src/stills.html`：六段的定格总览。
- `src/anim.html`：`draw(拍)` 画一帧，负责镜头、换场、夜色和题签。
- `tools/sheet.mjs 拍1 拍2 …`：抽几拍拼成联系表，先看再渲。
- `tools/render.mjs --jobs=4`：整片并行渲染，`--end=拍` 只渲前一段试看。
  - 2786 帧、每帧上万个 SVG 元素，单线程约 1 小时，8 路约 7 分钟。
  - **每路约占 2–3GB 内存**。32GB 的机器开 8 路会把内存吃到九成以上，所以默认 4 路，内存大再加。
  - 每一路必须各开一个浏览器。同一个浏览器里的后台标签页截图会报 `Page.captureScreenshot: Internal error`。
  - 每一路先压成一个视频段，再用 concat 拼起来，最后配上 wav。

## 流程

1. 先定剧情，再写配乐（`music.md`），最后让画面按拍长出来。
2. 先出六张定格定方向，再做一段换场试做，然后才铺整片。
3. 出片前自己检查：
   - 联系表要看；
   - 关键帧要截全分辨率看清楚：换场中间、主角回头那一下、光点亮起。
