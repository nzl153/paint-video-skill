# 共点蒙太奇：同一个形状，始终落在画面同一个点上

范例是《一口》（发布时也叫《甜甜圈与牛仔》）：25.8 秒。一只甜甜圈几乎铺满画面，孔里有个牛仔骑着马一路狂奔。每一拍孔里换一种画风，外圈晚一拍接过孔里刚用过的那种画风，一共接力了 24 种。最后回到甜甜圈，镜头拉远，甜甜圈被咬了一口。

代码在本仓库的 `montage-kit/`：
- `engine/film.mjs`：一帧画面是两层，孔里一层、外圈一层；
- `engine/timeline.mjs`：拍子和 `STEPS` 接力表；
- `engine/rider.mjs`：牛仔和马的共用骨架；
- `styles/*.js`：24 种画风，每种导出 `drawRing` 和 `drawInner`；
- `music/score.js`、`music/sfx.py`：配乐和音效；
- `engine/stylepreview.mjs`、`engine/gallery.mjs`：单种画风的三联图和全部画风的总表。

用 Node 加 `@napi-rs/canvas` 直接出帧，不开浏览器，整片 774 帧单进程约 1.5 分钟。用法：`npm run sheet` 出联系表，`npm run audio` 导出配乐并混上音效，`npm run video` 出整片。配乐用了 DRSKit 真鼓，下载和整理方法跟 `fluid-kit` 一样，只看画面不用下。

## 什么叫共点蒙太奇

- 很多毫不相干的画面快切、加速，最后急刹停住；
- 每一刀都让同一个形状落在画面的同一个点上，这就是「共点」，也是全片的不变量；
- 形状随你定：一条正弦、一个圆、一道竖线都行。
- 对应的专业说法是快切蒙太奇加图形匹配剪辑（graphic match cut）。

**开工先定三件事**：共点是什么形状、放在画面哪个位置、急刹停在哪几幅主画面上。

## 两种打法

### 一刀一个世界

每一刀都是一幅新画面，各画各的，只是那个形状一直落在同一点。比如一条正弦：示波器屏幕上的波形，切成海浪的轮廓，切成心电图，切成山脊，切成一根弹着的琴弦……越切越快，最后急刹。

- 每幅画面写成一个 `t` 的纯函数，剪辑表决定哪一秒放哪一幅。
- **批量写画面时一定要给参考图。** 只给文字描述，写出来的几乎全是「空画面中间一条细线」；给一张同类片子的联系表，马上就铺满了、有体积、景别也拉开了。
- **急刹停住的主画面最容易显得弱**，因为停留时间最长。它的要求和快切画面一样：铺满、有体积、有景深。
- **开头那件实物要写实**：靠真实环境（桌面、杯子、背景虚化）加旧化痕迹，而不是干净的渐变；整件东西都要出镜，不能只拍局部特写。
- **起势要顺**：先从黑场淡入，让人看清是什么，再启动。第一帧就闪就响会很突兀。
- **故障转场只出现在画面内部**（比如屏幕里），整个画面一起撕裂会像穿模；故障要配声音。

### 画风接力（《一口》）

同一个画面分成两层，画风在两层之间错拍接力：

- 外圈是一个环形物体，几乎铺满屏幕；孔里是一段连续不断的动画。
- 每一拍孔里先换一种画风，外圈晚一拍接过孔里上一拍的画风。`STEPS` 里连续写两次同一种画风，外圈就能追上孔里（片中迈布里奇那张老照片就是这么停住的）。
- 外圈的物体也跟着画风换：素描里是一卷胶带，水墨里是一笔圆相，油画里是一只眼睛，彩色玻璃里是玫瑰窗。
- 首尾都是甜甜圈，最后拉远咬一口，共点第一次被打破。

**做新花样之前，先用一张时间轴把结构复述一遍**：哪一层、在什么时候、变成什么。「两层错拍接力」和「钻进孔里换下一个世界」听起来很像，做出来是完全不同的两支片子。

## 连续动画：共用骨架，画风只管「怎么画」

- 孔里的动作要跨 24 种画风不断，所以骨架只有一套（`makeRider(t, hole)`），每种画风拿到同一组关节坐标，自己决定怎么画：素描是排线，像素是方块，热成像是温度色带，X 光是骨头。
- **骨架要做到解剖级别**：腿分段，按宽度剖面扫出轮廓；动作照迈布里奇的奔马关键帧；头有下颌和鼻孔，鬃毛和尾巴一缕一缕；骨架还附带肌肉线、马具、衣褶这些细节线条，给画风去用。
- 用粗管子拼出来的马和人，换什么画风都只会显得简单、像拼凑。

## 24 种画风怎么写

- 每种画风是一个文件，导出 `drawRing(ctx, W, H, t, hole, info)` 和 `drawInner(ctx, W, H, t, hole, rig, info)`。`film.mjs` 负责裁圆、挖孔、叠层和孔边的阴影。
- 先写两个样板（甜甜圈和素描），再交给别的 agent 并行写其余的。给它们的东西：
  - 样板的三联图：这种画风在孔里、做外圈、两层都是它；
  - 自查工具 `engine/stylepreview.mjs <id>`，写完自己出图看；
  - 写清楚外圈物体要随画风换，孔里的动作不能断。
- 交齐后用 `engine/gallery.mjs` 排成总表一起审，偏弱的打回去返工一轮。《一口》两路并行各写 11 种，打回 7 种，返工一轮后都立住了。

## 配乐和节奏

- 西部奔马，D 大调，100 拍每分钟，一拍 0.6 秒，**一步画风就是一拍**，马蹄每拍落地一次。弦乐跳弓打奔马的节奏，圆号唱主题；中段画风改成半拍一换；迈布里奇那张照片处急刹；回到甜甜圈时收成钢琴和竖琴。
- **觉得节奏慢，别改拍速，改时值。** 画面是卡拍的，拍速一动全片都要重排。改成双倍时值就行：跳弓半拍一组，踩镲满十六分，军鼓每拍一下。
- 每次换画风配一记「唰」加一声低音闷响，咬一口是单独一个音效；音效全用 numpy 合成（`music/sfx.py`），混在配乐下面。
- **响度标准化要跑两遍，第二遍用 linear 模式。** 单遍 loudnorm 是动态的，会把安静的开头提响。

## 检查清单

- 按拍取联系表：每一拍孔里和外圈分别是什么，接力有没有错位。
- 相邻帧平均亮度差超过 4/255 的地方逐帧看，查闪烁。做法：ffmpeg 输出 `scale=160:90` 的灰度 rawvideo，numpy 读成 `(帧, 90, 160)`，逐帧算平均亮度，报出相邻差大于 4 的帧；再找「和前后两帧都差得多、前后两帧彼此却很像」的单帧异常。
- 换画风那一拍前后几帧单独取样，查孔边有没有露缝、外圈有没有穿到孔里。
- 只看画面不看说明，问自己「看完记住了什么」，要和开工前写下的那一句话对得上。
