# 科普讲解片（HTML 演示 + 代码合成声效 + 配音）

用户要「科普视频」「讲清楚某个发现或原理」「知识区那种短片」时用这份。范例是《用光，打开大脑》：2026 年诺贝尔生理学或医学奖（光遗传学），3:05，有旁白。全部代码在本仓库的 `explainer-kit/`，**新片直接复制它当底座**，清空 `src/scenes-*.js` 里的场景后重写。

## 和其他几套的区别

- 不用 p5.brush，用纯 Canvas 2D。图示要的是干净、准确、读得懂，笔刷质感只是点缀。每帧 60–130ms。
- **允许写字**：字幕、章节标签、图示标注都是科普片的一部分。手绘短片那条「不写字」在这里不适用。
- 每一场可以换一种画风，跟着内容走，比如显微镜下的水、纸面图示、卡哈尔墨线、荧光显微、俯视实验场地、铜版画剖面、点阵视角。画风服务于「这一场在讲什么」。
- 声效全部用代码合成；旁白用 edge-tts。画面、声效、旁白共用一份时间轴。

## 流程

1. **选题先查新闻**：时效题（比如诺奖）先搜到获奖者、颁奖词和原始报道。几个候选里挑**因果链能画出来、最后能落到普通人身上**的那个，给用户一句推荐理由。
2. **核对事实**：片里出现的每个年份、人名、数字都要有出处。模型记得的东西也要搜原文核一遍。查不到的细节就换成不需要它的说法，别编。
3. **先给用户看分镜表**：一行一场，写清时长、画面、字幕要点。再定一个**贯穿全片的不变量**（范例里是「一束光」：蓝光先后打在藻上、膜上、神经元上、小鼠头上，最后变成琥珀色打进眼底）。
4. 用户点头后再写代码，顺序是：`timeline.js` → 场景 → 联系表检查 → 声效 → 旁白 → 连续帧检查转场 → 出片。

## 文件结构

| 文件 | 干什么 |
|---|---|
| `src/timeline.js` | 每一场的起点、所有事件时间（光子到达、开关灯、放电时刻），还有确定性随机数。浏览器里是全局变量，Node 里用 `require` 读进声效脚本。**画面和声音都只从这里取时间**，所以咔哒声和门打开永远对得上 |
| `src/core.js` | 数学、笔触、发光（`glow` / `glowLine` / `beam`）、纸纹、颗粒、文字、`label()` 引线标注、字幕与章节、场景调度、四种转场、时间拉伸 |
| `src/scenes-a.js`、`src/scenes-b.js` | 场景写成 `scene(起点, (ctx, lt, t) => {...})`，接缝写成 `seam(时刻, 时长, 'zoom'/'ripple'/'sweep'/'fade', 参数)`；文件末尾填 `CAPS`、`CHAPTERS`、`THEME` |
| `src/voice.js` | `tools/voice.js` 生成的旁白数据：时间拉伸锚点、每句的位置、自动切好的字幕 |
| `tools/voice.js` | 旁白稿；edge-tts 逐句生成，计算时间拉伸，自动切字幕 |
| `tools/audio.js` | 纯代码合成 `out/audio.wav`，并混进旁白 |
| `tools/shot.mjs` | `--times=..` 出联系表，`--video --fps=30` 出 MP4，同时混入 wav |
| `index.html` | 播放器：可暂停、拖动，音频以 `audio.currentTime` 为准对齐 |

字体用 `@fontsource/noto-sans-sc`（OFL 许可），`npm install` 时装进 `node_modules`。页面先用 `document.fonts.load` 把片子里用到的字加载完，再把 `READY` 置真；`shot.mjs` 等到 `READY` 才截图。

## 画面规矩

- **字幕**：放在底部居中，40px 无衬线，一句话一屏，每秒不超过 5–6 个字。底下垫一层**椭圆形**淡底，矩形会露出两侧硬边。`THEME` 按底色切换深浅两套字色。
- **章节**：左上角放「01 / 池塘里的绿藻」，加一根陶土色竖线，小而克制，让观众知道自己在第几步。
- **标注**：`label(文字, 目标点, 文字位置, 局部时间)`，引线先拉出来，字再淡入。浅色底上默认带纸色描边，压在别的东西上也读得清。
- **主体要大**：讲谁就把谁放大放在画面中心。范例里的绿藻一开始只占画高的 12%，放大到 1.7 倍才像主角。
- **状态变化要夸张，一眼就能看出来**：门开时两半要推开一大截；被感染的细胞要从和别人一样变成通体发蓝。**变之前必须和其他东西长得一样**，否则会提前露馅。
- **同一组几何复用**：墨线神经元和荧光神经元是同一份 `NEURONS` 数据，直接淡入淡出，就成了「同一块组织换一种看法」的转场。
- **静态又重的东西缓存成纹理**：画完的墨线、荧光背景层、柔光束都用 `texture(key, …)`，只算一次。
- 光束先用 `blur` 渲进半分辨率纹理，再放大使用。几层多边形直接叠出来，边缘会很硬，显得廉价。

## 转场

四种都在 `core.js` 的 `TRANS` 里。每个接缝挑一种跟内容有关的：

- `zoom`：绕一点推进去，下一场从**大于 1** 缩回 1（从小于 1 放大会露出黑框）。适合「放大到眼点」「推进瞳孔」。中心可以传函数，跟着移动的目标走。
- `ripple`：从一点扩开一圈带光的波纹。适合「离子涌进 → 电信号扩散」。
- `sweep`：一道光带扫过画面，适合换颜色的场景切换。光带透明度要低（0.2–0.3）。
- `fade`：同一组几何换一种画法时用。

做完要拍连续帧检查：每个接缝前后 2 秒取 8 帧。只看首尾帧发现不了露边和跳帧。

## 声效（`tools/audio.js`）

全部从零合成，48kHz 立体声 16-bit：

- **底音**：每场一个和弦（4–5 个正弦加一点二次谐波，左右声道微失谐），场与场之间交叉淡化 3 秒，音量用 LFO 慢慢起伏。
- **轻拨弦**：从第二场起每 0.75 秒拨一个和弦音，给全片一个不吵的节拍。
- **音效零件**：`pluck` 拨弦、`bell` 不和谐泛音的钟声、`boom` 音高往下掉的低频咚声、`whoosh` 噪声扫频、`spike` 电生理放电的咔哒声（4ms 双相脉冲）、`click`、`blip`、`hum` 持续的嗡声、`shimmer` 一团细碎的亮音。
- **事件对齐**：时间都从 `TL` 里取。画面里周期性的东西（比如 `sin(lt*9 + k*1.3)` 的峰）要反解出峰值时刻再放声音。
- **混响**：走发送总线，每声道四个梳状滤波器加两个全通滤波器。
- **母带**：先用 `tanh` 软限幅，再归一化到峰值 0.89。
- **一定要量响度**：合成完按每 4 秒打印一次 RMS，各段应落在 -19 到 -25 dB。范例的第一版里，水声比其他声音响了 15dB；只靠想象是听不出来的。

```bash
node -e "const b=require('fs').readFileSync('out/audio.wav');const sr=48000,n=(b.length-44)/4;let s='';for(let t=0;t<n/sr;t+=4){let a=0;for(let i=t*sr;i<Math.min(n,(t+4)*sr);i++){const v=b.readInt16LE(44+i*4)/32768;a+=v*v}s+=t+'s '+(10*Math.log10(a/(4*sr))).toFixed(0)+'  '}console.log(s)"
```

模型听不到声音。交付时要说明声效只按数据检查过，质感和节奏要用户自己听。

## 配音（edge-tts，旁白推着画面走）

`pip install edge-tts`。它用的是微软 Edge 朗读的神经网络语音，旁白文字会发到微软的服务。网络连不上时设环境变量 `TTS_PROXY=http://<代理地址>`。

- **选声音**：先用同一句生成 3–4 个试听，让用户挑。中文常用的几个：
  - `zh-CN-YunyangNeural`：新闻主播腔，沉稳，范例用的就是它。
  - `zh-CN-YunxiNeural`：年轻、活泼。
  - `zh-CN-YunjianNeural`：浑厚，戏剧感强，容易像营销号。
  - `zh-CN-XiaoxiaoNeural`：女声，亲切。
- **语速**：`--rate=-5%` 时大约每秒读 4.5 个字。

做法如下：

1. **按原字幕时段写旁白稿**：每行写成 `[时段起, 时段止, 读的话, 字幕]`，时间用原时间轴 τ。外国人名读中文译名，字幕写原文。片名、片尾这种画面上已经有字的，字幕填 `null`。
2. **逐句生成**：文件名里带文本哈希做缓存，只重做改过的句子。用 ffmpeg 的 `silenceremove` 掐掉首尾静音，转成 48k 单声道 wav，量出每句的真实时长。
3. **时间拉伸**：每个旁白时段的新长度取 `max(原长, 读完 + 0.7s)`，时段之间的空隙保持原长，得到一组分段线性的锚点 `[τ, t]`。
   - 画面：`renderFrame(t)` 先 `unwarp(t)` 换回 τ，场景、转场、章节、字幕颜色都按 τ 画；只有字幕按真实时间显示。
   - 声效：每个音效的起点都过一遍 `warp(τ)`，持续时长不变，所以不会变调；逐采样的循环（底音、水声）用 `unwarp(t)` 求权重。
   - 拉得最多的段落动画会放慢到 0.6 倍左右，看着没问题；再慢就该删减那句旁白。
4. **自动切字幕**：长句在标点处切成每屏不超过 24 个字，按字数比例分配读音时长，去掉末尾的逗号和句号。
5. **控制总长**：脚本会逐句打印「读音时长 / 原时段长」。范例第一版把 2:46 拉到了 3:15，删减最长的四句后变成 3:05。

**混音**：人声直接叠加，不进混响。人声包络（起音 30ms、释放 0.6s，**提前 0.15 秒看人声**，开口前就先压下去）把其余所有声音压低约 7dB。检查方法：对每句旁白，分别量「句中」和「句后空隙」的 RMS 做对比，人声应比底下的背景高 9–12dB。

## 出片

```bash
npm install
node tools/voice.js      # 有旁白时先跑，生成 src/voice.js 和 out/voice/
node tools/audio.js
node tools/shot.mjs --video --fps=30 --out=out/video.mp4
```

范例 3:05，共 5550 帧，每帧约 90ms，整片渲染约 9 分钟，成片 68MB。
