# 作业本涂鸦：圆珠笔、彩铅、手机俯拍的本子

范例是《页边》：38 秒，带配乐。作业本页边上刚画好的一只小团子，笔一离开它就活了，在纸上溜了一圈；听见笔回来，又跑回原位假装没动过。一镜到底，不画人，没有文字。分镜见 `doodle-kit/STORYBOARD.md`。

代码在本仓库的 `doodle-kit/`：
- `render.mjs`：渲染（和 `crayon-kit` 是同一个）；
- `src/`：引擎、主角、纸面和全片时间线；
- `music/score.js`：配乐；
- `tools/audio.mjs`：导出配乐。

用法：`npm run sheet` 取九个时刻拼成联系表，`npm run audio` 导出配乐，`npm run video` 出整片（先跑 audio）。

## 什么时候用这套

- 要「纸」「本子」「涂鸦」「圆珠笔」「上课乱画」的感觉时。
- 这种画风拆开是三样东西：圆珠笔勾线（蓝红两色）、彩铅斜排线涂色（涂不满、有留白）、手机俯拍的作业本（有光照明暗和纸纹）。**它不是素描。** 可爱靠的是页边那些小画和小纸条，不是主体本身。
- 别和精致的材质混搭。比如刺绣精致贵重，随手涂鸦可爱随意，两种气质放在一起会打架。
- 不画人，主角是一只涂鸦小东西，正好绕开代码最弱的人物全身。

## 引擎（纯 2D canvas，不用 p5.brush）

渲染器参数和蜡笔那套一样（`--sheet`、`--strip`、`--frames`、`--encode`，见 `crayon.md`）。页面要提供 `window.renderAt`、`renderSheet`、`SHOTS`、`DUR`。

| 文件 | 内容 |
|---|---|
| `src/doodle.js` | 画法：`bp()` 圆珠笔、`bpFill()` 圆珠笔涂实、`pencil()` 彩铅、`scrawl()` 假手写 |
| `src/stage.js` | 整页贴图、木桌、实物圆珠笔 `realPen()`、相机 `camera()`、渲染入口 |
| `src/cast.js` | 主角 `guy(c, x, y, s, P)` |
| `src/scene.js` | `PAGE_ART`：纸上不会动的笔记和页边小画 |
| `src/timeline.js` | 走位 `G(t)`、脚印、红圈、墨点、两支笔、相机关键帧 |

**圆珠笔 `bp(c, pts, o)`**：
- 用 multiply 叠在纸上，沿线长按低频噪声变化粗细和浓淡，偶尔断墨（透明度降到 0.45）。起笔加一个小墨点。
- `reveal` 控制画到哪里，函数返回笔尖坐标，实物笔就跟着它走。
- 参数：`col`、`w`、`seed`、`a`、`skip`、`smooth`、`gob`、`blend`。
- **静止的笔迹不抖。** 真圆珠笔印在纸上是不会动的，只有「活着」的东西才抖。

**彩铅 `pencil(c, shape, col, o)`**：
- 在草稿层裁到形状里画斜排线，每条线的长短、浓淡、弯度都随机；再用纸齿遮罩（`destination-in`）抠出颗粒；最后 multiply 到纸上。
- 参数：`ang` 排线角度、`gap` 线距、`a` 浓淡、`reveal` 涂到哪里（沿排线方向扫过去）、`clip` 再裁一层（暗面只涂在身子里面）、`cross` 交叉排线。
- 每个目标画布配一张同尺寸的草稿层（`scratchFor`），所以整页贴图和每帧画面都能用。

**假手写 `scrawl()`**：
- 每个字母从七种形里随机挑一种（驼峰、小圈、闭合圆、高圈、下行圈、带横的 t、带点的 i），连成一笔，整体右斜 0.3，加逗号。
- 只用一个公式（`x - r·sin`）的话，整页看着全是「mmm」。分成字母形状以后才像真笔记。
- 看不出任何内容，所以不算违反「不写字」。

**整页贴图**：
- 纸、纤维、印刷的横线和页边线、全部笔记、页边小画（云、星星、小花、瓢虫、半个太阳），再加一层左上亮、右下暗的拍照光，先按 2 倍分辨率画进一张画布。每帧只把它贴上去，再画会动的东西。
- 每帧只要 2–10 ms，912 帧 4 进程 40 秒渲完。
- `PG.padL` 把纸往左多铺了 480。原位离纸边太近的话，特写镜头左边会一直露出一条木桌。木桌只该在最后拉远时露出来。

**实物圆珠笔 `realPen(c, x, y, o)`**：
- 金属笔尖、透明笔杆、能看见里面的墨芯，渐变高光。
- 影子是关键：笔是斜着拿的，离纸越远的部分影子错开得越多，抬笔（`lift`）时影子变远变虚。一支「有影子的真笔」在纸面上，一下就把照片感立住了。
- 笔尖跟着正在画的线走，取最近 5 个时刻的平均位置。换笔画时平均值和当前位置拉开，就自动算成一点抬笔。

**相机**：关键帧 `[秒, cx, cy, z]`，用 Catmull-Rom 过点，加一点手持漂移（几像素加极小的旋转）。

## 主角和「活着」

- 小团子：桃色彩铅打底，右下用橙色压暗面，蓝圆珠笔勾边（加半圈错开的第二遍，像随手描了两次），头顶一根嫩芽，两只小脚，脸上两团粉。脚底中点定位，`s` 是身子半径，用的 64。
- 中景镜头 z 1.6–1.9 时，主角约占画高的四分之一。
- **「活着」和「死物」要一眼分得开**：
  - 活着：线条每秒抖 8 次，身下有一点影子，还垫一层纸色，底下的字不透上来，像从纸上站了起来；
  - 定住：三样全停，回到纸上。
  - 结尾它扑回原位定住，这个开关本身就是笑点。
- **离开原位留压痕**：圆珠笔用力会在纸上压出浅浅的印子（浅灰线条，左上方加一道白色高光）。它跑回来时要严丝合缝地落进去：先落歪，再赶紧挪正。
- `guy()` 的 `P` 参数：
  - 状态：`alive`、`draw`（被笔画出来的进度，按轮廓、脚、嫩芽、眼、嘴、手、彩铅、脸红的顺序）、`ghost`；
  - 身体：`sq`、`lean`、`lift`、`walk`；
  - 脸：`look`、`blink`、`wink`、`mouth`、`bigEyes`；
  - 其他：`arms`（down、up、poke、push、hold、wave）、`sprout`、`smudge`、`shadow`。

## 戏怎么排

- **一镜到底跟着它走。** 转场就是镜头移动，开头从纸色淡入，结尾拉远到整页再淡出。
- **结尾拉远是收尾的包袱**：脚印、甩下的墨点、拆开的红圈都留在纸上，「它假装没动过」被整页证据拆穿，正好呼应开头。纸上的痕迹一律是「出现之后一直留着」：脚印按 `G(t)` 预先算好，带出现时刻。
- **笔是另一个角色，只露笔不露手**：蓝笔是画它的人，红笔是批改的人。笔回来之前先让它在画面上方盘旋，主角才有东西可怕。蓝笔停在画外的话，狂奔那段就没有威胁感。
- **俯拍里所有动作都要在纸面这个平面上读得出来**，「离开纸面」只能靠影子交代。
  - 反例：「抓起红圈从头上掀过去」。俯拍看不出「举起」，连续帧里就是圈自己往上滑走了。
  - 改法：拽住线头往外走，圈从线头那里一点点被拆开，拖出一条红线，底下开出一个缺口，它从缺口钻出去，松手后线头落下弹一下。

## 配乐：跟着动作写（mickey-mousing）

整套做法见 `music.md`，这里只记这一种写法。乐谱在 `music/score.js`，采样和其他 kit 一样从 jsDelivr 下载后缓存在 `.cache/`。

- 画面先定，配乐按秒写：`B = s => s * BPM / 60`，速度固定 100。每个动作配一个音乐动作：
  - 笔在画：竖琴一笔一个音往上走，点眼睛是两声钢片琴；
  - 眨眼：钢片琴一声；左看右看：两下拨弦；
  - 蹑手蹑脚：低音拨弦走八分音符，单簧管吹跳音；
  - 翻红线：单簧管一口气冲上去，落地一个和弦；
  - 钻进墨团：竖琴往下滑，低音拨弦一记「扑通」，然后弦乐震音渐强；
  - 被红笔圈住：圆号压低，「!」是一个不协和的拨弦和弦加定音鼓，画圈时震音小提琴半音往上爬；
  - 狂奔：转 D 小调，拨弦十六分音符，定音鼓和低音每半拍一下，圆号重音；
  - 扑回原位：竖琴冲上去，落地那一下全体停住。
- **静的地方要真静。** 笔离开到它眨眼之间、它定住之后，都只留一点铺底。「停住」的笑点靠音乐突然断掉。
- 追逃段必须是全片最急、最响的。初稿里狂奔比前面蹦跳还轻 5 dB，按秒量响度才发现。
- 模型自己听不了，只能按秒量 RMS 看起伏对不对。交片时要明说配乐没人听过。

## 实测

- 静帧 0.5–1 秒（第一次要建整页贴图），之后每帧 2–10 ms；912 帧 4 进程 40 秒。
- 配乐离线渲染加两遍响度标准化，一次约 1 分钟（采样走缓存）。
- 成片 CRF 17 约 116 MB。圆珠笔细线和彩铅排线都很吃码率。

## 拿它拍整首歌的剧情 MV

这套画风后来拍过一支 4 分钟的剧情 MV（配的是有版权的歌，代码不在仓库里），下面是从那支片子里攒下的经验。

### 先定情绪和剧情，再挑手段

- 初稿的故事是团子挂在纸边上往回翻页，叫醒本子里的涂鸦伙伴一起开派对。画风没问题，剧情、分镜、转场都不行：
  - 角色挂着纸边飞进下一页，很怪；
  - 两个小人陪坐对视，意思不明；
  - 快速翻页时小人一张张往上跳，像穿模；
  - 小东西们太快乐，和告别的歌反着来。
- 根子在于故事是围着引擎能做的花活编的（翻页、涂鸦活过来），情绪没先定。
- ⇒ **配歌的长片先定情绪和剧情，再挑能演它的手段。** 引擎能做什么，不是故事的理由。

### 不画人，用东西演人

改好的版本讲两个同桌在草稿本页边轮流接着画，毕业以后另一支笔再也没来接。

- **两支实物笔就是两个人**：朴素的蓝圆珠笔从左边进；挂小铃铛的红笔从右边进，铃铛随笔的速度晃（`realPen` 加 `charm` 参数，笔杆颜色用 `barrel` 参数）。
- **本子在桌上滑 = 同桌之间传本子**：两张课桌拼在一起，中间一道缝和铅笔画的三八线；整本书在桌面上平移加转角度。本子滑过去出画一半，滑回来时多了一幅画，对方画的过程不用拍。
- **接笔的节奏是情绪核**：前面完整演三次「蓝笔退出 → 本子滑走 → 滑回来多一笔」。到「现在」照同样的节奏再演一次，本子滑回来什么都没多。
- **过去和现在靠光、桌子、纸区分**：过去是下午的窗光（窗格影子随时间变成雨天、傍晚、天黑）、课桌、新纸；现在是台灯、深色书桌、发黄的纸。
- 颜色专用：全片红色只给其中一个人，卷子上的红叉之类一律不用。

### 引擎要加的东西

- `drawParts(c, parts, k)`：一幅涂鸦写成笔画清单，`{p}` 是圆珠笔线，`{fill}` 是彩铅，`{dot}` 是涂实的点；按笔画总长度分配进度，笔在两笔之间空中移过去也算时间，返回笔尖坐标。猫、伞、井字棋、火车、星星都这么画，笔速自然。
- **页贴图按「画完了哪些」做键**，例如 `'v|页码|每个条目画没画完|旧不旧'`：画完的条目烤进贴图，正在画的那一条每帧现画在上面；翻页时飞起来的纸自然带着当时该有的涂鸦。旧化先盖在过去的笔迹上，「现在」新画的笔迹画在旧化之后，所以是新墨。
- 窗光：四格窗户的光斑，窗框影子落在桌上和纸上，可选雨水影子往下流；几种天光之间插值。
- 相机改成单调的三次插值，缩放在 log 空间插值：在停住或掉头的关键帧处速度为零，不会冲过头。
- **歌词手写**（字幕也是一种视觉效果）：
  - 手写字体（例如 Google Fonts 的 Long Cang，OFL 授权）用 `@font-face` 加载，并在 `ready` 之前 `document.fonts.load`；
  - 每个字随机歪一点、上下错一点，按演唱时间从左上往右下一个字一个字「写」出来；
  - 读一下字底下的亮度，是深色桌面就换浅色笔迹，用 screen 混合；
  - 歌词文件是繁体的要先转简体（或反过来），和画面统一。

### 转场

- **跨时代不要硬切。** 一帧之内灯、桌、纸、涂鸦全换，非常生硬。改成约 2 秒的叠化：同一时刻两个时代各画一遍（全局强制时代，画到离屏画布），按进度叠起来；相机运动不动，所以像回忆浮上来。
- **「过了很久」不要合上本子切场景。** 改成一镜到底的延时：光慢慢变（台灯 → 雨夜 → 冬天的白天）；茶杯、围巾、课本从画面外滑进来放下，再滑走；本子在中间自己合上、打开。

### 翻车和检查

- 只画两只猫耳朵当「试画」，远看像字母「MM」。要带上半个头才认得出是猫。
- 俯拍的背影拥抱：手臂要搭在肩膀的高度、两个角色挨近、头歪过去靠着，才看得出是抱。手臂放在身子下半截，看着像地上的线。
- 歌词在画面下方时，主体的脚要在画面 y < 900 以内，否则会被字压住。特写时把相机 cy 往下放。
- 远景里格子线细密的地方（比如封三的课程表）会锯齿闪烁，因为 2 倍贴图缩得太小。
- 检查：先出整片联系表，16 帧一张，每段首中尾；转场处出连续帧；交付后再从成片 mp4 抽帧核一遍。

### 实测

- 每帧 0.1–1 秒。页贴图要重画时每张 1–3 秒，翻页多的段落最慢。独显 4 路渲 4 分钟（5928 帧）约 40 分钟，显卡只用 17%，瓶颈在 JS（彩铅排线、贴图重画、歌词读像素）。
- **局部返修**：
  1. 把那一段的帧挪开（不删）；
  2. 跑 `--frames --keep-frames --range=a:b`，注意 range 的帧号边界，挪多了要补；
  3. 编码出无声版，再用 ffmpeg 合上音频（`-af apad -t 片长`）。

  28 秒一段重渲约 3 分钟。
- 成片 CRF 17，4 分钟约 480MB。
