# 皮影画风

驴皮刻的小人贴在一块被油灯照亮的幕布上，操纵杆从下面伸上来，配锣鼓点。来自短片《两只手》：60 秒，96 BPM，11 镜，没有歌，声音全部用代码合成。引擎、整部短片的代码、分镜和合成器都在仓库的 `piying-kit/`。

## 什么时候用这套

- 用户要皮影、剪影、戏台、民俗、光影的感觉，或者想做一支不配歌、只用打击乐的短片。
- 和蜡笔一样是纯 2D canvas，不用 p5.brush。每帧绘制 2–10ms。
- 没有歌就没有版权问题：锣鼓是合成的，成片可以直接带声音发。

## 起新项目

1. 复制 `piying-kit` 到新目录（已经装过依赖的话连 `node_modules` 一起复制，排除 `out`）。没装过就在新目录里 `npm install`，只有一个依赖 `puppeteer-core`，装之前问用户。
2. 先跑通：`node render.mjs --sheet=5,10,25,40,50,55 --cols=3 --w=480 --out=out/check/sheet.jpg`，再看样张 `--loop=front --sheet=1` 和人设表 `--loop=cast --sheet=1`。
3. `studio.html` 的脚本顺序：`config` → `piying`（引擎）→ `cast`（角色）→ `scenes/keys.js`（布景零件和样张）→ `scenes/film.js`（整部戏）。新片把 `film.js` 换成自己的。
4. 声音：`python sound/synth.py --end=60 --out=out/sound.wav`（要 numpy、scipy），渲视频时 `--audio=out/sound.wav` 合进去。

`render.mjs` 的参数和蜡笔那套相同（`--sheet`、`--strip`、`--stills`、`--clip`、`--frames`、`--encode`、`--loop`、`--crop`）。`--crop-at` 会报错：皮影引擎没有全局相机。60 秒 1440 帧用 `--clip` 单进程约 2 分钟。

## 引擎原理（`src/piying.js`）

- **幕布**：`screen()` 画一个以灯为中心的径向渐变（热白 → 暖黄 → 橙 → 暗棕），再乘一层布纹。灯用 `LAMP = {x, y, k}` 控制，`k` 从 0 到 1 就是点灯和熄灯；`flick()` 让灯火一直轻轻闪。
- **一片皮**：`piece(regions, o)` 把一片皮单独画在草稿层上，顺序是：
  1. 按颜色填色（一片皮上可以染几块颜色）；
  2. 贴皮纹，皮纹贴在这片皮自己的坐标里，跟着皮走，不会在皮上「游泳」；
  3. 描边；
  4. 用 `destination-out` 刻镂空；
  5. 再补刻完以后才画的细节（眉眼、铆钉）。

  最后整片用 `multiply` 叠到幕上。好处是重叠的地方自然变深，刻空的地方透出灯光，和真皮影一样。
- **离幕远近**：`o.blur` 和 `o.a` 表示这片皮离幕多远，越远越糊越淡。全局的 `DEPTH` 可以给整场戏加模糊，拍景深的时候用。
- **镂空花样** `cut.*`，都在局部坐标里调用：

| 函数 | 用途 |
|---|---|
| `dot` `ring` `diamond` `crescent` | 圆点、圆环、菱形、月牙 |
| `swirl` | 卷草纹 |
| `line` `poly` `wave` | 折线、多边形、波浪 |
| `row(x0, y0, x1, y1, n, r, kind)` | 一排同样的花 |
| `fill(poly, step, fn, margin)` | 在一个形状里按格子铺满花，离边至少留 `margin` |

  - 用 `fill` 的时候，边缘一定要留余量，否则皮会「散」。
  - 皮影好不好看，一半在刻得密不密：大片素皮看着像剪纸。
- **`union: true`**：几块同色的形状只描外轮廓。树冠这种由好几个圆拼成的形状用它，否则里面会露出一圈圈的线。
- **其它零件**：`rod(A, B)` 画操纵杆，上细下粗、略糊；`stageFrame()` 画台口（雕花横楣、台沿、立柱）；`GROUND` 是台口地面线；`kf(t, K)` 是关键帧工具，缓动写在每段结尾那一帧上，值可以是数组。

## 角色（`src/cast.js`）

`puppet(x, ground, u, P)`：身高约 110u，关节在腰、肩、肘、腕、颈，每一节是一片单独的皮，铆钉处重叠。

- **空脸**：脸整个刻空，只留轮廓、眉和眼。这是传统生角的画法，灯一透，脸就是亮的。
- **姿势参数**：
  - `dir`：朝向；
  - `lean`：前倾；
  - `head`：点头，正值是低头；
  - `armF`、`armB`：前后两只胳膊，各是 `[肩, 肘, 腕]`，往前为正；
  - `legF`、`legB`：两条腿；
  - `bob`：身体上下起伏；
  - `spin`：翻跟头；
  - `lift`：离幕，0 是贴着幕；
  - `ling`：翎子摆动；
  - `rebel`：第四根杆子。
- **活气来自手颤和灯火**：皮影是硬的，不要学蜡笔那样抖笔触。每个关节加一点低频噪声 `tr()`，像操纵的人手在微微动，再加上灯火闪，就够了。
- **操纵杆一律往左下斜**（操纵的人坐在幕后左边），脖子一根，两只手各一根，自动画。要让观众一眼认出「不对劲的那根杆子」，就让它从另一边斜着伸上来。
- **离幕的投影**：皮影被拿离幕布时，影子会按灯的位置投影放大，不是原地放大：`x = LAMP.x + (x - LAMP.x) * grow`，地面线也一样算。
- **`bob` 加在屏幕坐标里**，在旋转之前加。否则翻跟头转到头朝下时，「往上跳」会变成往下，脑袋戳进地里。

## 皮影戏怎么演才好看

- **机位固定在台口**，和真皮影戏一样。换场靠灯光和推进来的布景片，不切镜头。只有剧情需要揭开什么的时候才切一次，这一下才有分量。
- **侧身演**：皮影永远是侧面，朝向靠翻身。「啪」地一下直接翻过去就对了，这本来就是皮影的动作语言，不用做中间帧。
- **动作砸在锣鼓点上**：
  - 亮相、踢腿、被拽，都要在「锵」响的那一帧**到位**，不能提前摆好。
  - 做法是前面蓄住（身子一沉、胳膊往后收），到拍子前约 0.1 秒才起动，用 `easeOut` 在拍子后 1 帧左右到位，再加一个小回弹 `spring()`。
  - 如果用 `backOut`，或者关键帧放早了，到位就会比锣早 2 帧，看起来像没踩上点。用 `--strip` 拍这一拍前后的每一帧来核对。
- **亮相**：前手高举过头、后手弯在身后、两腿一前一后，翎子「嗡」地一弹，灯也跟着亮一下。
- **反差靠「不听话」**：胳膊卡住（冲出去撞到看不见的墙，弹回来，抖）、被第四根杆子拽着踉跄（杆子先动，身子后跟上，脚最后），这些都比正常的武打好看。
- **收尾**：拱手、鞠躬，然后熄灯，只留幕上一点余光。

## 幕后机位：镜像 + 剪影

《两只手》第 7–9 镜从幕后看过去：幕透着光，皮影左右反过来，一个人的剪影攥着两根杆子。

- **镜像不用另写**：先套一个变换，`translate(x0 + W*k, y0)` 再 `scale(-k, k)`，然后原样调用台口那套画法（幕、远山、树、`puppet()`），画出来的就是背面看过去的样子。姿势函数台口和幕后共用同一个，所以切镜头前后动作是连着的。这时候要关掉 `puppet()` 自带的杆子（`rods: false`），改成从关节画到人的手里。
- **剪影加轮廓光**（`silhouette(drawFn)`），画三遍：
  1. 在画面上画一整块暗色；
  2. 在草稿层上用暖色再画一遍；
  3. 在草稿层上用 `destination-out` 加模糊，把同一个形状挖掉。

  挖完只剩一圈往里渐隐的边。再乘一道竖向渐变（背后是亮幕的地方亮，幕下面慢慢暗），最后用 `lighter` 加到画面上。所有部件是一起挖的，胳膊压在身体上的地方不会出现内线。
- **人要压在亮幕上**：头的剪影落在发亮的幕前面才好看，落在幕下面的暗处就只剩一块黑。
- **景深**：镜头推到手上时，给幕上的东西加 `DEPTH` 模糊，杆子和手保持清楚。
- **布纹按屏幕像素贴**：相机缩放在 1 倍左右时，布纹会出方格状的摩尔纹。在世界坐标里画好幕的渐变之后，把 transform 重置成单位矩阵再乘布纹。

## 声音：代码合成锣鼓（`sound/synth.py`）

- **乐器**：每件都是「几个衰减的正弦分音 + 一点噪声」，numpy 就能写。

| 名字 | 是什么 |
|---|---|
| `bang` | 梆子，硬木，短而亮 |
| `dan` | 碎鼓（板鼓），高、紧、干 |
| `tang` | 堂鼓，低沉 |
| `xiao` | 小锣，打下去音高往上挑，这是京剧小锣的特征；`slide=-1` 改成往下滑，用来逗 |
| `da` | 大锣，音高往下沉，余音长 |
| `bo` | 钹；`choke=True` 捂住，只剩半声 |
| `qiang` | 「锵」，就是钹 + 大锣 + 堂鼓一起；`decay` 调余音长短 |
| `roll` `accel_roll` | 滚奏、越滚越快 |
| `whoosh` `breath` `ignite` `crackle` | 风声、吐气、点灯、灯芯噼啪 |

- **按拍号排**：`CUES` 里写 `(BT(拍号), 乐器, 参数)`，拍号和画面共用同一套。
- **混音**：加一点舞台混响（衰减噪声当冲激响应，`fftconvolve`）。先按峰值归一化再过 `tanh` 软削顶。直接写 int16 的话，峰值超过 1 会溢出成爆音。
- **agent 听不到声音**：画波形图，把每条 cue 的拍号画成竖线，核对时值和削顶。音色好不好只能请用户听，交付时要说清楚这一点。
- **不要合成旋律**：锣鼓点合成出来很像样，笛子、胡琴合成出来很廉价。要旋律就让用户给音频。
- **安静比响更有力**：一段戏越来越快的鼓突然停死，接着切镜头，只剩灯芯声，这比一直响有劲得多。

## 检查

- 每个镜头照常出联系表。动作踩点用 `--strip` 拍那一拍前后的每一帧，看「到位」落在哪一帧。
- 翻跟头、甩向灯这种快动作，用 `--strip` 确认脑袋有没有戳进地里、影子有没有按灯的方向放大。
- 刻花密度放大看：`--crop=x,y,w,h` 截全分辨率。
