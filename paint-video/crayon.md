# 蜡笔画风

油画棒蜡笔加连环画分格，绘本小人约 3 头身。来自 MV《呆头鸟》：2:29，68 BPM，36 镜，3590 帧，江南小镇，一天从清晨走到夜里，男主「一慌就变成呆头鸟」。引擎和一段 16 秒的 demo 在仓库的 `crayon-kit/`。

## 什么时候用这套

- 用户要童趣、绘本、蜡笔、儿童画、连环画的感觉，或者看腻了水彩。
- 水彩、水墨照旧走 p5.brush 底座（`SKILL.md`）。蜡笔这套**不用 p5.brush**，是纯 2D canvas，自成一套。

## 起新项目

1. 复制 `crayon-kit` 到新目录（已经装过依赖的话连 `node_modules` 一起复制，排除 `out`、`sub/ov_full`）。没装过就在新目录里 `npm install`，只有一个依赖 `puppeteer-core`，装之前问用户。
2. 先看 demo 跑不跑得通：`node render.mjs --sheet=1,4,8,12 --cols=4 --w=480 --out=out/check/sheet.jpg`，再 `--loop=cast --sheet=1` 看人设表。
3. `studio.html` 里的脚本顺序：`config` → `crayon` → `cast` → （`shotlist_data`）→ 零件库 `lib`、`lib2` → 自己的镜头文件 → 最后注册镜头的文件。把 `demo.js` 换成自己的。
4. `cast.js` 里的她、他、呆头鸟是《呆头鸟》的角色。新片可以直接改，也可以照它的参数写法新写。

`render.mjs` 支持的参数（文件头有完整说明）：
- `--sheet`、`--strip`、`--stills`、`--frames`、`--encode`、`--clip`、`--loop`，用法和 p5.brush 底座相同。
- 局部放大只能用 `--crop=x,y,w,h`（屏幕像素）。`--crop-at` 要跟着世界坐标走，蜡笔引擎没有全局相机，用了会直接报错。
- fps 由 `--fps` 决定（默认 24），`--frames` 和 `--encode` 要给同一个值。
- 场景文件有语法错误、或者一个镜头都没注册时，命令会失败退出，不会出空白图。
- `--frames` 会给帧记代码签名，代码改了就停下，让你选 `--force`（旧帧挪到 `out/frames_old_*` 后全部重渲）或 `--keep-frames`（改过的那几镜的帧已经手动挪走，只补缺的）。

## 引擎原理（`src/crayon.js`，约 230 行）

- **蜡只沾在纸齿上**：每个色块先实心画在草稿层，再用「纸齿」遮罩 `destination-in` 抠掉一部分，缝里露出纸，这就是蜡笔感。
  - 纸齿 = 纤维噪声（沿一个方向拉长）+ 中噪声 + 大噪声 + 白噪声。
  - 按覆盖率切成几档：`light` .42 / `mid` .64 / `heavy` .82 / `line` .9 / `solid` .97。
- **笔触会轻轻抖**：遮罩每个形状随机旋转、偏移，并且以 `BOIL = 8`（每秒换 8 次）换种子，像逐帧重画。随机数全由「本帧第几个形状 + boil 帧号」决定，所以帧仍是 t 的纯函数，可以乱序并行渲染。
- **最后两遍**：整帧叠一层纸（`makePaper`），再乘一层颗粒和暗角（`makeGrain`）。
- **速度**：单帧绘制 10–50ms（不含 JPEG 编码和写盘；4 进程渲染折合每帧 40–70ms），全片 3590 帧 4 进程约 4 分钟，可以放心多渲几轮。p5.brush 是每帧约 1 秒。

**API**：

| 函数 | 用途 |
|---|---|
| `blob(pts, col, o)` | 色块 |
| `stroke(pts, lw, col, o)` | 线。下笔重、收笔轻，断续靠 `line` 档 |
| `dot(x, y, r, col, o)` | 圆点，实心档 |
| `scribbleFill(pts, col)` | 大面积底色，两个方向来回涂 |
| `cam(cx, cy, z, rot)` / `push()` / `pop()` | 镜头 |
| `panel(x, y, w, h, fn)` | 分格：格子自带纸底和粗蜡笔框，格内坐标从 0 开始 |
| `flash(k)` | 纸白一闪 |
| `ell()` / `rect()` / `through()` | 形状点，`through` 是 Catmull-Rom 平滑 |
| `shots([[t0, fn], ...])` / `LOOPS.name = fn` | 注册镜头 / 单独的循环样张 |

`blob` 的常用参数 `o`：
- `d` 覆盖档；
- `ang` 笔触方向（度）；
- `j` 边缘抖动（px）；
- `line` / `lw` 描边的颜色和粗细；
- `a` 透明度；
- `under` 垫底色；
- `d2` / `c2` 叠第二遍。

蜡层是半透明的，底下的颜色会从纸纹缝里透上来，所以 `blob` 默认先垫一层纸。

**两个全局开关**，每帧在 `renderFrame` 里清零，镜头函数里按需设：
- `UNDER_DARK`：夜景用。色块底下不垫纸，垫本色压暗一档，否则纸纹缝里透出白，夜景像下了雪。
- `NIGHT_TINT`：柳树这类颜色写死的布景，夜里往 `#2a3f5c` 压暗，否则夜里的柳树亮得像荧光。

**天色**：场景函数接收 `tone`（0 白天 → 1 黄昏 → 2 夜），每种颜色用 `TN(k, 白天色, 黄昏色, 夜色)` 取。房子的窗户在夜里自动亮起。一天从早走到晚，只要逐镜改 `tone`。

## 角色（`src/cast.js`）

- 绘本小人约 3 头身，用**脚底中点 (x, y)** 定位，`u` = 头的半径（像素）。
- 尺寸（1080p）：中景 u 约 50–90（《呆头鸟》人设 58），脸特写 260–270。和 p5.brush 里 `clawd()` 的 `u` 不是一回事，别套用 20–28。
- 姿态是一个参数对象 `P`，完整字段写在 `cast.js` 开头的注释里：
  - 朝向和头：`face`、`look`、`tilt`；
  - 动作：`walk` 走路相位、`sq` 压扁拉长、`dy` 离地、`arms` 手的位置、`handsOnly` 只露出小手；
  - 表情：`eyes`（`dot`/`wide`/`arc`/`happy`/`spiral`/`wink`）、`mouth`、`brow`、`blush`；
  - 情绪特效：`heat` 脸从下往上红透、`ahoge` 呆毛弹、`steam` 冒气。
- `human(x, y, u, P, 'her'|'him'|路人名)`、`bird(x, y, u, P)`。
- 路人换发型和衣服颜色就行（`EXTRAS`），远处的人群用剪影 `crowdSil`。
- 零件库 `lib.js`、`lib2.js`：爱心、蜡笔、月亮、河灯、萤火虫、落花、蝴蝶、路人、街巷、石拱桥、船、花枝、红线心。

## 画面经验

- **变身梗**：一慌就「噗」一团烟（`poof`）变成呆头鸟，第二遍副歌反过来是她变。
  - 情绪涨到顶才变：先 `heat` 红透，再冒气，然后噗。
  - 烟团要盖住整个人，变身发生在烟最大的那几帧里，看不到中间形态。
- **分格砸格**：连环画格子一拍砸下一格，带回弹缩放（`backOut`），歌词里的叠字一字一格。demo 的 B 段就是。
  - ⚠️ **最后一格落在重拍上时，切镜别放在同一拍**，否则那一格一帧都不出现。第三格就是这样一直没显示，切点挪到下一拍之后半拍才修好。
- **前奏用蜡笔一层层画出世界**：`revealLayer` 按层显形（天 → 远山房子 → 河和桥 → 近岸柳树），边缘是锯齿，边缘上画一支蜡笔（`crayonStick`），看得出是在「画」。
  - 蜡笔要大（330×52）、要在画面里。第一版太小还跑出画外。
- **结尾拉远成绘本**：书页左边是开头的房间，右边是结尾两只鸟，旁边一支用短了的红蜡笔。最后渐变回纸白。
  - 首尾呼应就是 `SKILL.md` 说的「一条不变的约束」：红线贯穿全片。
- **躲在树后要露出身体的一部分和脚**：demo 第一版男主「像长在树上」。原因是两只袖子横搭在树干正面，脚全被挡住。
  - 改法：人站在树干后侧，露出半边袍子和一只脚，整个人往外歪（`lean`），手只露出小手。
- **heat 停在一半像戴口罩**：只能做成动态涨上来，别停在中间。
- **晚景别变成灰紫一片**：黄昏镜 `tone` 给到 1.08 左右是金色；1.5 附近的中间值发脏，直接跳到 1.85 的夜。
- **特写要紧**：脸特写 u=260–270，窗景要把画面填满。第一版 u 偏小，看着就是「松」。
- **桌子要有实心前板**：否则桌后的人的衣服会从桌腿之间露出来。
- **小心道具挡脸**：飘带、茶杯、蝴蝶飞行路线、爱心，第一版都出现过划过或盖住脸，出拼图时专门查脸。
- **男主别画方脸**，圆脸才是绘本的样子。

## 蜡笔字幕（`crayon-kit/sub/`）

画面照旧不写字，字幕按 `mv-workflow.md` 第 10 节单独做一层。和毛笔版的差别：

- **字体**：马善政楷书（Google Fonts，OFL），从 8 款里挑的。
- **融进蜡笔画面**：
  - 字的质感用 `crayon.js` 同一套纸齿配方（Python 移植），也以 BOIL=8 抖动。
  - 字底下垫一层毛边蜡块：整句字形往外胀、糊开再切，边缘带纸齿。白天是纸色，夜里是深蓝 `#1f2748`。
  - 出场：一个字一个字从上往下写出来，前沿是毛的。
  - 退场：成块掉蜡加变淡，**在切镜前 0.4 秒就擦完**，不拖进下一个镜头。
- **字号 112**（1080p）：86 号看着「太小，也有点不清晰」。
  - 笔画 MaxFilter 5 加粗。
  - 纸纹只做成表面的一层（`a = 字形 × (.55 + .45 × 纸齿)`），别让纸齿把笔画抠断，不然就糊了。
- **墨色按场景定，不按局部亮度**：月亮、灯晕会让夜景局部很亮，按亮度判断就会在夜里出现浅色衬底，像贴了张标签。`song.json` 的 `night_from` 写从哪一刻起全是夜景。
  - 夜里是暖白字 `#fbe7bf` 配深蓝衬底，白天是墨色 `#3b2c26` 配纸色。
  - 夜景里砸进一格暖橙色分格时，在 `override.json` 里给那句加 `"swap": [时刻, 字色, 衬底色]`，在那一刻换成深色字。
- **叠字按拍出**：`song.json` 的 `beatwords` 写叠字最后一个字的时刻，每个字落在自己那半拍上，最后一个字卡在重拍。副歌第二遍用 `repeat` 整体平移。
- **两列一起找位置**：第二列在第一列左边、顶端对齐，同一段尽量待在同一侧，不左右乱跳。

**人物避让用探针，比猜颜色准得多**（`sub/probe.mjs`）：
- 包住 `human`、`bird` 等函数，统计它们调用 `wax()` 画出的所有点，经过当前变换得到屏幕包围盒，每秒记 6 帧，写成 `boxes.json`。
- 分两档：人、鸟、手、烟是 `hard`（绝不能压），路人、灯笼摊、爱心是 `soft`（重罚）。换了片子按自己的函数名改 `probe.mjs` 里的 `TAGS`。
- 2:29 的片全片跑一遍约 8 分钟，只要画面不改就不用重跑。
- 局限：没走被包住的函数画的东西（比如镜头里单独画的胳膊）探不到，拼图里还要人眼查。

**跑一遍**：先 `node render.mjs --frames` 渲好全片帧，照 `sub/song.example.json` 写好 `sub/song.json`，然后：

```bash
node sub/probe.mjs --fps=6      # 在项目根目录跑，写 sub/boxes.json
cd sub
python layout.py                # → specs.json，打印找不到空位的句子
python review.py                # → ../out/check/rev_*.jpg，每句三帧
python final.py --encode --base ../out/video.mp4 --out ../out/video_sub.mp4
```

**实测**：自动排版 18 秒；全片字幕层 6 进程加合成约 3 分钟。整轮 28 句只有 4 句要手摆（四格镜里两句、一句避开手、一句避开路人）。
