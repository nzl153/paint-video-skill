# 《页边》

一句话：作业本页边上刚画好的一只小涂鸦，笔一离开它就活了，在纸上溜了一圈，听见笔回来又赶紧跑回原位假装没动过，只有满纸的脚印、被它拆开的红圈出卖了它。

## 世界与配色
- 俯拍一页写满笔记的横线本，像手机拍的照片：左上来光、右下偏暗，纸有纤维和颗粒。
- 圆珠笔：蓝 `#27348b`（主线）、红 `#c23a32`（老师的红笔）、黑（涂掉的错字）。
- 彩铅：主角橙桃色，嫩芽绿，脸红粉。笔记本横线浅蓝、页边线淡红。

## 贯穿母题
- 主角原位：画好的地方，离开后留下一圈压痕（圆珠笔压出的印子），最后它要严丝合缝落回去。
- 活着 = 线条在轻轻抖（每秒 8 次）、身下有一点影子；不动 = 线条静止、没影子，回到纸上。

## 逐镜读点（一镜到底，镜头跟着它走）
| 时间 | 读点 |
|---|---|
| 0–5.0 | 蓝笔在页边一笔画出它：轮廓 → 眼睛 → 彩铅涂色，笔抬走 |
| 5.0–8.2 | 静止一秒。眨眼，左看右看，嫩芽一弹，线开始抖，身下浮出影子 |
| 8.2–12.1 | 走出原位（留下压痕），走到红色页边线前，一跳翻过去 |
| 12.1–15.5 | 踩着横线一路蹦到正文里，身后一串小脚印 |
| 15.5–19.6 | 发现一团涂掉的错字，戳一下，一头钻进去，墨团乱抖，从另一边钻出来一身墨点，甩掉 |
| 19.6–24.6 | 红笔来了，一圈把它圈住。它推了推，拽住线头往外走，红圈一点点被拆开，从缺口钻出去，线头落下弹一下 |
| 24.6–29.5 | 蓝笔的影子回来了，「!」冒汗，顺着脚印一路狂奔回去，再翻一次红线 |
| 29.5–33.8 | 扑进压痕，落歪了，赶紧挪正，定住不抖。蓝笔回来在它旁边添一朵小花，走了 |
| 33.8–38 | 它偷偷眨一只眼。镜头拉远到整页：脚印、墨点、拆开的红圈都还在。淡出 |
